# 欧陆战争 · 手机版

一个参照「欧陆战争」玩法做的回合制战棋小游戏，纯前端、零依赖，手机浏览器直接打开即可玩。

## 怎么玩

部署到任意静态服务器后，手机打开该地址；或者本地直接双击 `index.html`（不依赖模块加载，file 协议也能跑）。

起一个本地服务（推荐，手机上同网段访问）：

```bash
cd eu-war-mobile
python3 -m http.server 8123 --bind 0.0.0.0
```

然后手机访问 `http://电脑局域网IP:8123/`。

## 操作

| 操作 | 说明 |
|---|---|
| 点己方部队 | 选中，显示蓝色的可移动格与红色的可攻击目标 |
| 点蓝格 | 移动过去；途经城市且该兵种可占领时自动占领 |
| 点红格 | 攻击该敌军；相邻时会被反击 |
| 招募 | 打开面板选兵种，再点黄色框的己方空城放置 |
| 结束回合 | 交给电脑行动，电脑打完自动交还 |

## 规则

- 兵种：步兵 / 装甲车 / 坦克 / 火炮，造价 60 / 90 / 120 / 140 金
- 每格移动消耗取决于地形：平原 1、森林 2、山地 3、河流不可通行（河上 3 处浅滩可过）
- 防御加成：平原 1.0、森林 1.2、城市 1.3、山地 1.4、首都 1.5
- 伤害 = 攻击方攻击力 × 血量比 ÷ (100 + 防守方防御力 × 地形加成) × 1.55，最低 6 点
- 相邻被打会以 55% 力度反击；火炮射程 2，可在射程外输出
- 收入：每个城市每回合 25 金，首都 40 金；占领额外 +20 金
- 胜利：占领敌方首都或歼灭敌方全部部队；超过 30 回合按控制区、兵力、金币依次判定

## 文件结构

```
eu-war-mobile/
├── index.html              页面、样式、底部操作栏
├── js/data.js              地形 / 兵种 / 地图 / 规则常量（UMD，可被 Node 引用）
├── js/core.js              规则引擎：移动、战斗、占领、经济、AI（纯函数，无 DOM）
├── js/ui.js                Canvas 渲染与触摸交互
└── tests/
    ├── core.test.cjs       规则引擎单元测试（12 项）
    ├── soak.cjs            双方 AI 长跑测试（80 回合压力）
    ├── cdp.cjs             Chrome DevTools 协议的薄封装
    ├── browser.test.cjs    真实浏览器集成测试（11 项）
    ├── shot.cjs            截图脚本
    ├── run-browser.sh      一键跑浏览器测试
    └── run-shot.sh         一键出三张截图
```

## 测试

```bash
node tests/core.test.cjs      # 规则引擎，12 项
node tests/soak.cjs           # 双方 AI 长跑，检查不崩溃、能正常结束
bash tests/run-browser.sh     # 真实 Chromium 里跑交互测试，11 项
```

## 已知边界

- 只有一张地图、一个对手，没有存档、没有音效
- AI 是贪心策略：优先打得到的目标，否则向最近的敌方单位或城市推进，不做多回合规划
- 没有撤销操作，点错只能等下一回合
