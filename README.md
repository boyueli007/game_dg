# 欧陆战争 · 手机版

参照《欧陆战争》做的回合制战棋，六边形网格、军事剪影单位、军事风界面。纯前端零依赖，手机浏览器直接打开即可玩。

## 怎么运行

```bash
cd eu-war-mobile
python3 -m http.server 8123 --bind 0.0.0.0
```

手机访问 http://电脑局域网IP:8123/ 。也可以直接双击 index.html（无模块加载，file 协议可跑）。

## 画面构成

- **六边形战场**：11 列 x 14 行，odd-r 偏移尖顶六边形，竖屏比例
- **地形**：平原（草纹）、森林（树冠）、丘陵（起伏）、河流（波纹，仅 3 处浅滩可过）、城市（建筑群）、首都（旗帜）
- **单位剪影**：坦克（车体 + 炮塔 + 履带）、装甲车（轮式车体 + 炮管）、火炮（底座 + 长身管 + 双轮）、步兵（头盔 + 躯干 + 步枪）
- **军事 HUD**：顶部双方阵营与金币、回合与行动方；任务条显示目标与控制区计数；底部单位信息卡（立绘 + 攻防 + 兵力条）+ 出兵/结束回合
- **战斗反馈**：伤害数字飘字（受伤红、反击橙），选中黄框，可达格淡蓝、可攻击格淡红

## 操作

| 操作 | 说明 |
|---|---|
| 点己方部队 | 选中，显示可达格与可攻击目标 |
| 点蓝格 | 移动，进入据点自动占领 |
| 点红格 | 攻击，相邻会被反击 |
| 出兵 | 打开兵工厂，选兵种后点闪烁据点部署 |
| 结束回合 | 交给电脑，电脑行动完自动交还 |

## 规则

- 兵种：步兵 60 / 装甲车 90 / 坦克 120 / 火炮 140 金
- 地形消耗：平原 1、森林 2、丘陵 2、河流不可通行
- 防御加成：平原 1.0、森林 1.2、城市 1.3、丘陵 1.35、首都 1.5
- 伤害 = 攻击力 x 血量比 ÷ (100 + 防御力 x 地形加成) x 1.55，最低 6
- 反击：防守方射程内以 55% 力度反击；火炮射程 2，可远程输出不吃反击
- 收入：城市 25 金 / 回合，首都 40 金；占领额外 +20
- 胜利：占领敌方首都或全歼；超过 30 回合按控制区、兵力、金币依次判定

## 目录

```
eu-war-mobile/
├── index.html              页面、军事风样式、HUD、兵工厂面板
├── js/data.js              地形 / 兵种 / 地图 / 规则常量（UMD）
├── js/core.js              六边形规则引擎 + AI（纯逻辑，无 DOM）
├── js/ui.js                六边形渲染、剪影绘制、飘字、触摸交互
└── tests/
    ├── core.test.cjs       规则引擎单元测试 15 项
    ├── soak.cjs            双方 AI 长跑测试
    ├── cdp.cjs             调试协议封装
    ├── browser.test.cjs    浏览器集成测试 12 项
    ├── shot.cjs            截图脚本
    ├── run-browser.sh      一键浏览器测试
    └── run-shot.sh         一键截图
```
